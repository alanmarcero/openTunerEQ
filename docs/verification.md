# Verification

Local macOS arm64 run for v1.2.0, 2026-11-03:

- Release builds: VST3, AU, standalone app and all three test suites.
- CTest: core, processor/UI and spectrum suites pass. New coverage checks analyzer defaults, saved off/style settings, older session recall, UI controls, Alt/Option-click placement, pre-EQ capture and bit-identical audio with analysis on/off.
- Spectrum coverage: 8/22.05/44.1/48/96/192 kHz, calibrated tones, bass, mono, right-only and opposite-polarity stereo, Nyquist bounds, stopped transport, capture gating, editor lifetime and queue overflow. A 24 Hz consumer with 16/31/32/64/257-sample blocks at 192 kHz checks the small-buffer case.
- pluginval 1.0.4: VST3 passes strictness level 5.
- Actual JUCE editor snapshots for Spectrum, Bars and Spectrogram generated by `build/plugin_tests assets/native-ui.png` while processing a synthesized multitone input. Inspected for visible frequency peaks and readable EQ curves/controls.
- Independent source review caught AU parameter version hints and short-block queue exhaustion. Both are fixed; a separate paced probe verified the capture fix and partial-packet resets across disable, reopen, rate changes and overflow.

These checks exercise the processor and native editor. They do not constitute a listening session in a full DAW. GitHub Actions performs the macOS universal and Windows x64 release checks separately.
